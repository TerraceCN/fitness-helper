# 用户输入

- 性别（男/女）
- 身高（cm）
- 体重（kg）
- 年龄
- 训练方案（减脂/增肌）
- 训练时间：
  - 早饭后练（早起）
  - 早饭后练（晚起）
  - 午饭前练
  - 午饭后练
  - 晚饭前练
  - 晚饭后练
  - 夜里练
- 力训熟练度（新手/有基础/老手）
- 有氧消耗(d)：每日平均值

# 计算值

## 身体数值

- BMI指数：体重（kg）/身高的平方（m）
  - 正常：18.5-23.9
  - 超重：24-28
  - 肥胖：>28

## 热量设计

### 基础数据

- 基础代谢(a)：Mifflin-St Jeor方程
  - 男性基础代谢=体重kg×9.99+身高cm×6.25-年龄×4.92+5
  - 女性基础代谢=体重kg×9.99+身高cm×6.25-年龄×4.92-161
- 无运动总消耗(b=a÷0.7)：在没有力训、有氧的情况下，基础代谢约占人体热量消耗的70%，其余的热量消耗为食物热效应和活动消耗（因为无运动，活动消耗就是日常活动消耗）
- 力训消耗(c)：
  - 男性，150大卡（新手）、200大卡（有基础）、250大卡（老手）
  - 女性，100大卡（新手）、150大卡（有基础）、200大卡（老手）

### 平衡热量

- 力训日(e1=b+c+d)
- 休息日(e2=b+d)

### 应吃热量

- 力训日(f1=e1×0.64)
- 休息日(f2=e2×0.64)

## 饮食总览

### 力训日

- 碳水：配额（g/kg）×体重（kg）
- 蛋白质：配额（g/kg）×体重（kg）
- 脂肪：男性60g（120kg体重以上加到70g） 女性50g

### 休息日

- 碳水：配额（g/kg）×体重（kg）
- 蛋白质：配额（g/kg）×体重（kg）
- 脂肪：男性60g（120kg体重以上加到70g） 女性50g

表格内单元格数值为：力训日碳水配额/休息日碳水配额/蛋白质配额

## 饮食组成

### 力训日饮食

需要根据“训练时间”，形成不同的餐食顺序。

各种餐食顺序的碳水和蛋白质占全天配额如下（碳水占比%/蛋白质占比%）：

- 早饭后练（早起）
  - 早饭（练前餐）：15/20
  - 练后餐：35/20
  - 午饭（其他餐）：20/20
  - 晚饭（其他餐）：20/20
  - 零食/夜宵：10/20
- 早饭后练（晚起）
  - 早饭（练前餐）：20/20
  - 午饭（练后餐）：40/30
  - 晚饭（其他餐）：30/30
  - 零食/夜宵：10/20
- 午饭前练
  - 早饭：20/20
  - 练前餐：15/0
  - 午饭（练后餐）：35/0
  - 晚饭（其他餐）：20/30
